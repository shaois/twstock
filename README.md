# 台股 20 日獲利機率動態排行（V90）

本專案只保留一個投資目標：使用已完成的日線資料，估計未來 20 個交易日的淨報酬，並以同期 0050 為比較基準。

## 唯一正式流程

1. GitHub Actions 每日分五批更新 200 支股票的日線。
2. 最後一批完成後，以相同日期的 0050 日線建立比較基準。
3. `predictor.py` 對全部 200 支股票套用同一套 20 日模型。
4. V90 每天使用最新完整日線，重新排列全部具備完整資料的股票。
5. 主要依「20 日扣除 0.6% 交易成本後仍獲利的校準機率」排序；同機率時依超越 0050 機率、預期超額及預期報酬排序。
6. 不限制 5 檔或 10 檔，也不建立或沿用固定持倉名單；20 日只代表預測與績效評估期限。
7. 基準日單日漲幅達 7%，或漲幅達 5% 且收盤位於當日區間頂端 95%，保留排名但標示等待回測。
8. 歷史回測與正式上線績效分開揭露；實績採下一交易日開盤作為可執行進場價。
9. `index.html` 與 `app.js` 只讀取 `universe.json` 和 `predictions.json`；AI 只解釋結果，不能改排名。

## 正式檔案

- `predictor.py`：唯一預測模型、歷史驗證、每日機率排序與實績追蹤。
- `update_all.py`：每日五批資料更新與模型輸出。
- `verify_model.py`：模型契約與歷史驗證檢查。
- `main.py`：網站與 AI API 代理。
- `index.html`、`app.js`：只呈現 20 日模型。
- `cache/price.json`：股票已完成日線。
- `cache/benchmark.json`：0050 已完成日線。
- `cache/universe.json`：固定 200 支股票名單。
- `cache/predictions.json`：唯一正式模型輸出。
- `cache/prediction_log.json`：每日完整排行與可執行的 20 日實績紀錄。
- `cache/progress.json`：五批更新進度。

## 啟動

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

## 驗證

```bash
python -m unittest discover -s tests -v
python verify_model.py
```

## 重要限制

- 模型只使用執行日以前已完成的日線，盤中波動不會改變排名。
- 每筆歷史標籤固定比較第 20 個交易日，並扣除 0.6% 交易成本。
- 排行是研究資訊，不等同自動買進或資金配置建議。
- V90 不沿用任何舊版持有名單，每個完整交易日都重新排序。
- 正式實績以訊號後下一交易日開盤進場、第 20 個交易日收盤評估，並扣除 0.6% 成本。
- 歷史績效不保證未來獲利；本工具僅供研究，不構成投資建議。
