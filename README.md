# 台股 20 日研究排行 V91

固定 200 支股票每天重新排序，由使用者自行判斷標的。20 日是預測與評估期限，沒有固定持倉名單。AI 只解釋結果。研究候選，非投資建議。

## V91 修正

- 訓練、時間順序歷史重播、上線追蹤共用交易結果函式：以0050交易日期為準，訊號後次日開盤進場，訊號後第20個交易日收盤評估。股票缺少該段日期時不移動到別的日期。
- 股票與0050各使用0.6%來回成本情境。超額=股票淨報酬－0050淨報酬；超越機率判定淨超額>0。這是模型假設，不代表ETF實際稅率或券商費率。
- 25/75分位區間與10分位下行情境採與機率相同的因子順位及波動度權重；風險分位數使用未截尾、未乘0.75的原始報酬，避免縮小損失尾端。
- 預期平均報酬維持既有±30%截尾、35%全域中位數、0.75收縮。機率仍採0.75向50%收縮，但明確標示未經獨立校準；這些參數沒有被宣稱為最佳值。
- 歷史重播與正式排行共用排序函式。排序順序：淨獲利估計機率、超越0050估計機率、資金流分數、預期淨超額、預期報酬、因子分數、股票代碼。
- 重播每20個0050交易日抽一截面；預測只使用標籤結束日早於訊號日的歷史資料，至少12期、最多40期。最多報告40個評估期。
- 五組名次分層每組20%，僅用於評估排行品質，不是持股上限。缺失結果照實計數，組別不完整時不計組合平均。
- 新增機率分箱、Brier誤差及訓練基準機率比較、風險區間涵蓋率。獨立未使用封存期數目前是0，沒有「驗證通過即可買」。
- 上線訊號同日不覆寫，已完成結果不重寫；晚於預定進場時點才記錄的訊號，標示為晚到訊號，不充當前瞻績效。舊版本紀錄不以新公式重算。
- 移除舊固定持倉函式、舊候選閘門及共同信心分數。

## 完整日線判斷

一般情況排除執行當日資料。只有台北18:00後重新從API抓到、格式有效且有成交的當日日線，並且200支股票至少90%及0050均確認，才納入當日；未確認的個股當日列會排除。18:00是保守政策緩衝，不是FinMind資料完成保證。若第一批在18:00前執行，可能需下一循環更新該批才能滿足覆蓋率。跨午夜照常使用前一天資料。

綠色按鈕只重新下載已發布快取，不會觸發GitHub抓資料；黃色按鈕開啟排行。更新包部署後須等待refresh-cache的200/200完成V91重建。

## 金鑰與後端

AI請求必須帶使用者自己的API Key；環境中的GROQ_API_KEY或NVIDIA_API_KEY不再作為後援。沒有個人金鑰的請求不呼叫上游。預設CORS僅允許 https://shaois.github.io 與 https://twstock-app.onrender.com，可由ALLOWED_ORIGINS（逗號分隔）設定自訂網域。CORS不是身分驗證，服務仍是使用者自帶金鑰的公開代理，不提供共享額度服務。

模型與訊息長度受限，回傳錯誤不回顯上游本文。GitHub Pages部署與Render後端部署需分別確認；上傳程式不代表Render已完成部署。

## 執行與驗證

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
python -m unittest discover -s tests -v
node tests/test_frontend_v91.cjs
python verify_model.py --report V91_VALIDATION_REPORT.json
```

verify_model只使用本機既有快取並輸出指定報告，不抓行情、不覆寫正式快取。歷史模擬與功能測試通過不代表有獲利能力。

## 必須保留的限制

- 固定200支名單沒有逐歷史日期成分紀錄，仍有選樣／存活者偏差。不能把此股票池的資金廣度稱為全台股市場。
- 過去資料已多次參與改版，時間順序重播仍不等於未曾使用的封存測試。下一步需累積V91公開後的前瞻資料。
- 既有日線正規化含股價跳變調整啟發式；不是完整除權息／公司行動總報酬資料，無法據此宣稱真實可執行績效。
- 假設次日開盤可成交，尚未完整處理滑價、漲跌停無量與市場衝擊。
- 有效樣本數只是權重集中度，不是獨立交易次數；同一期股票高度相關。
